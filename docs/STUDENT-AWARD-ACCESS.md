# รางวัลและเกียรติบัตรของนักเรียน

บัญชี Student เห็นเฉพาะรางวัลสถานะ Published ที่มีทะเบียนนักเรียนของบัญชีนั้นในรายชื่อผู้รับรางวัล รวมรางวัลที่ไม่ได้เปิดเป็นสาธารณะ บัญชีที่ยังไม่ผูกทะเบียนนักเรียนจะไม่เห็นรางวัลหรือเกียรติบัตรใด ๆ

กติกานี้ใช้กับหน้ารายการ การค้นหา รายละเอียด หน้าแรก สถิติ และรายงานทุกชนิดที่ใช้ ReportService รวมการส่งออก PDF, Word, Excel และพิมพ์ รายละเอียดรางวัลกลุ่มและรายงานรางวัลไม่แสดงชื่อนักเรียนผู้รับคนอื่น การแก้ StudentId ใน URL ไม่เปลี่ยนเจ้าของข้อมูลที่ดูได้

## ระบุเจ้าของไฟล์

- เปิดรายละเอียดรางวัลด้วยบัญชีที่แก้ไขรางวัลนั้นได้
- เมื่ออัปโหลด ให้เลือก “ผู้รับเกียรติบัตรสำหรับไฟล์ชุดนี้” ได้เฉพาะนักเรียนในรายชื่อผู้รับรางวัล
- สำหรับไฟล์ที่มีอยู่แล้ว ใช้ส่วน “กำหนดเจ้าของเกียรติบัตร” เลือกผู้รับแล้วกดบันทึก ระบบตรวจการแก้ไขพร้อมกันด้วย RowVersion
- ค่า “เอกสารส่วนกลาง” หรือไฟล์เดิมที่ยังไม่ระบุเจ้าของ จะไม่แสดงให้นักเรียนเห็น ไม่เดาเจ้าของจากชื่อไฟล์หรือจากรายชื่อผู้ร่วมรางวัล
- แต่ละไฟล์ระบุนักเรียนเจ้าของได้หนึ่งคน หากมีเกียรติบัตรแยกคน ให้อัปโหลดแยกตามเจ้าของไฟล์
- เมื่อเอานักเรียนออกจากรายชื่อผู้รับรางวัล นักเรียนจะเปิดทั้งรางวัลและไฟล์นั้นไม่ได้ทันที

รางวัลที่เผยแพร่แล้วแก้ไขได้ตามสิทธิ์เดิมของระบบ ผู้ดูแลระบบสามารถกำหนดเจ้าของไฟล์เดิมได้ ครูจัดการผู้รับไฟล์ได้ในรางวัลฉบับร่าง/ส่งกลับที่ตนมีสิทธิ์แก้ไข

การเปิด `/files/{id}` ทั้งตัวอย่างและดาวน์โหลดตรวจผู้รับไฟล์จากฐานข้อมูล ไม่อาศัยเพียงการซ่อนลิงก์ วารสารที่มีรายการรางวัลถูกรวมอยู่จะถูกซ่อนจากนักเรียนทั้งหน้าอ่าน QR และไฟล์ PDF เพราะ PDF ที่สร้างไว้ไม่สามารถแยกชื่อผู้รับตามบัญชีผู้ดูได้ วารสารที่มีเฉพาะกิจกรรมยังดูได้ตามเดิม

ข้อจำกัดนี้ใช้กับบัญชีนักเรียนที่เข้าสู่ระบบ การเผยแพร่แบบสาธารณะสำหรับผู้เยี่ยมชมและสิทธิ์เจ้าหน้าที่คงใช้กติกาเดิม ผู้ดูแลควรเลือกเผยแพร่สาธารณะให้ตรงกับเจตนาของเนื้อหา

## ฐานข้อมูลและการทดสอบ

Migration `20260927015531_AddCertificateStudentRecipient` เพิ่ม `portfolio.AwardCertificate.StudentId` แบบ nullable พร้อม index และ foreign key ไปยังทะเบียนนักเรียน โดยไม่ลบหรือเปลี่ยนเจ้าของไฟล์เดิม ไฟล์ยังเก็บเป็นไบนารีในฐานข้อมูล

เรียกทดสอบด้วย `dotnet run --project SchoolPortfolioPR.UiChecks -- --student-awards` ขณะเว็บเปิดที่ `http://localhost:5093` ใช้บัญชีทดสอบสองนักเรียนและ SuperAdmin จากไฟล์ credentials ส่วนตัว สร้าง fixture เฉพาะรอบและลบหลังจบ ครอบคลุมการอ่านข้ามบัญชี รางวัลกลุ่ม รายงาน การกำหนดผู้รับ อัปโหลด และการเพิกถอนสิทธิ์เมื่อออกจากรายชื่อผู้รับ
