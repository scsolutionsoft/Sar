# เปลี่ยนชื่อและโลโก้โปรแกรม

เข้าสู่ระบบด้วย SuperAdmin หรือ Administrator แล้วเลือก **ดูแลระบบ → ตั้งค่าโปรแกรม** (`/Branding`) หรือทางลัดในหน้าภาพรวม

1. กรอกชื่อโปรแกรม ไม่เกิน 100 ตัวอักษร
2. เลือกโลโก้ PNG, JPG หรือ WebP ขนาดไม่เกิน 2 MB แนะนำภาพสี่เหลี่ยมจัตุรัสพื้นหลังโปร่งใส ระบบแสดงภาพเต็มโดยไม่ตัดขอบ
3. กด **บันทึกการตั้งค่า** ชื่อและโลโก้จะใช้กับทุกบัญชีและหน้าสาธารณะเมื่อเปิดหน้าครั้งถัดไป ไม่ต้องรีสตาร์ตโปรแกรม

ชื่อแสดงในส่วนหัว ส่วนท้าย ชื่อแท็บ และหน้าเข้าสู่ระบบ โลโก้แสดงในส่วนหัว หน้าเข้าสู่ระบบ และไอคอนแท็บ เมื่อเปลี่ยนเฉพาะชื่อ ให้เว้นช่องอัปโหลดโลโก้ว่าง หากต้องการกลับไปใช้ไอคอนเริ่มต้น ให้เลือก **นำโลโก้ออกและใช้ไอคอนเริ่มต้น** แล้วบันทึก

ระบบตรวจสิทธิ์ทั้งหน้าอ่านและคำสั่งบันทึก ครู ประชาสัมพันธ์ ผู้อนุมัติ ผู้ดูแลฝ่าย ผู้ชม และนักเรียนแก้ไขไม่ได้ ถ้ามีแอดมินคนอื่นบันทึกระหว่างเปิดหน้าอยู่ ระบบปฏิเสธการบันทึกทับและให้เปิดหน้าใหม่

ค่าตั้งต้นคือ SchoolPortfolioPR และไอคอนโรงเรียน ไม่มีการเปลี่ยนชื่อโรงเรียนในทะเบียนข้อมูลพื้นฐาน หรือแก้ PDF ที่ส่งออกไปแล้ว

ข้อมูลอยู่ใน `portfolio.Branding` โลโก้อยู่ใน `portfolio.FileObjects.FileData` แบบ `varbinary(max)` เปิดสาธารณะได้เฉพาะโลโก้ปัจจุบันผ่าน `/Branding/Logo/{id}` การแก้ไขมีประวัติ Audit ตามปกติ Migration: `20260927033401_AddApplicationBranding`

ทดสอบการใช้งานด้วย `dotnet run --project SchoolPortfolioPR.UiChecks -- --branding` ขณะเว็บทำงานที่ localhost:5093 ชุดทดสอบคืนชื่อและโลโก้เดิมเมื่อจบ
