# ธีมและหน้าต่างดูไฟล์ร่วมกัน

ธีมใช้ฟอนต์ Sarabun ที่เก็บในโปรเจกต์ และสีแยกหมวด: ครามสำหรับกิจกรรม, ทองสำหรับรางวัล, เขียวสำหรับแฟ้มผลงาน/รายงาน, ม่วงสำหรับวารสาร. เมนูแยกภาพรวม/ผลงาน สื่อ/รายงาน ข้อมูลพื้นฐาน และดูแลระบบ ส่วนฟอร์มกิจกรรม/รางวัลแบ่งเป็นรายละเอียด หมวดหมู่ ผู้ร่วม และการเผยแพร่

รูปภาพและ PDF ใช้ `_MediaViewer.cshtml` และ `wwwroot/js/media-viewer.js` ร่วมกัน:

- กิจกรรม: ภาพปก แกลเลอรี และเอกสารแนบ
- หน้าเว็บไซต์: ภาพข่าวและกิจกรรมแนะนำ
- รางวัล/แฟ้มผลงาน: เกียรติบัตรและรูปภาพ
- รายงาน/แฟ้มผลงาน: ปุ่ม **ดู PDF** เปิดรายงานตามตัวกรองในป๊อปอัป
- วารสาร: ปุ่ม **ดู PDF** ในรายการและหน้า Flipbook; รูป QR เปิดขยายได้
- อัปโหลด: คลิกดูภาพหรือ PDF ที่เลือกไว้ได้ก่อนส่งข้อมูล

หน้าต่างรองรับเลื่อนไฟล์ ภาพย่อ ซูม พอดีจอ เต็มจอ เปลี่ยนหน้า PDF ดาวน์โหลด คีย์ลูกศร และ Esc. เมื่อปิดจะคืนโฟกัสไปยังปุ่ม/ลิงก์เดิม มีสถานะกำลังโหลดและข้อความกรณีไฟล์ไม่พร้อมใช้งาน ไฟล์ Word/Excel ยังคงดาวน์โหลดไปเปิดด้วยโปรแกรมที่รองรับ

ใช้ `_Files.cshtml` สำหรับรายการเอกสาร ส่วนลิงก์รูป/ไฟล์ในหน้าใหม่ใส่ attributes ต่อไปนี้:

```html
<a href="/files/FILE_GUID"
   data-media-preview
   data-media-type="image"
   data-media-title="ชื่อภาพ"
   data-media-group="ชื่อชุดภาพ">ดูภาพ</a>
```

`data-media-type` ใช้ `image` หรือ `pdf`; `data-media-group` ไม่บังคับ ถ้าใส่ค่าตรงกันจะเลื่อนดูในชุดเดียวกันได้ ชื่อไฟล์แสดงด้วย textContent. URL ต้องอยู่ origin เดียวกับเว็บ; สิทธิ์เข้าถึงไฟล์ยังตรวจที่ FilesController. PDF ใช้ PDF.js ภายในโปรเจกต์โดยปิด dynamic eval; PDF ก่อนอัปโหลดอ่านจาก File.arrayBuffer โดยไม่ส่งข้อมูลขึ้นเซิร์ฟเวอร์

## ตรวจหน้าจอ

```powershell
# เปิดเว็บก่อน ต้องมีชุดข้อมูลตัวอย่างเดิม
dotnet run --project SchoolPortfolioPR.UiChecks
```

ชุดตรวจนี้อ่านข้อมูลตัวอย่างและใช้ไฟล์ชั่วคราวในเบราว์เซอร์ ไม่เพิ่ม/แก้ไขข้อมูลในฐานข้อมูล ตรวจการซูมจริง ดาวน์โหลด การคืนโฟกัส รูป/PDF สลับกัน PDF หลายหน้า เต็มจอ หน้าจอมือถือ เกียรติบัตร รายงาน และกรณีไฟล์หาย หลักฐานภาพเก็บใน `artifacts/ui/`.

Smoke test เดิมปรับให้ดาวน์โหลด PDF ผ่านป๊อปอัป และตรวจแกลเลอรี/วารสารด้วยตัวดูไฟล์ร่วมกัน ชุดนี้ใช้ข้อมูลชั่วคราวและลบตาม ID ของรอบทดสอบใน finally ตามเดิม
