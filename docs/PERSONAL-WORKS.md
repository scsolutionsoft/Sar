# ผลงานของฉัน

ทุกบทบาทเปิดเมนู **พื้นที่ส่วนตัว → ผลงานของฉัน** ที่ `/MyWorks` ได้ รวมถึง Student และ Viewer โดยเลือกเพิ่ม 4 ประเภท: กิจกรรม รางวัล เกียรติบัตร และอัลบั้มภาพ

กรอกชื่อ วันที่ หมวดหมู่ หน่วยงาน สถานที่ บทบาท และรายละเอียด รางวัล/เกียรติบัตรเพิ่มระดับหรือผลรางวัลได้ หน้าแรกแบ่งการ์ดสีตามประเภท พร้อมจำนวนรายการ ตัวกรอง ค้นหาชื่อ/รายละเอียด/หมวดหมู่/คำบรรยาย และแบ่งหน้า รองรับมือถือ

## ภาพและเอกสาร

- อัปโหลด PNG, JPG, WebP หรือ PDF ครั้งละไม่เกิน 20 ไฟล์ ไฟล์ละ 10 MB รวมไม่เกิน 50 MB; อัลบั้มรับเฉพาะภาพ
- รูปและ PDF เก็บไบนารีใน `portfolio.FileObjects.FileData` และเปิดด้วยป๊อปอัปเดียวกับส่วนอื่นของระบบ
- เพิ่มคำบรรยายทั้งชุดหรือแก้แยกรายไฟล์ได้ ลิงก์คลาวด์รับ HTTP/HTTPS และเปิดต้นทางในแท็บใหม่ตามสิทธิ์แชร์ของบริการนั้น
- กด **เก็บ PDF เข้าคลังส่วนตัว** เพื่อใช้เอกสารต่อ นักเรียนเลือกเอกสารจากคลังเพื่อแนบแฟ้มยื่นเรียนต่อได้
- แก้ไข/ลบผลงาน หรือเอาไฟล์/ลิงก์ออกได้ PDF ที่เก็บเข้าคลังส่วนตัวแล้วจะยังอยู่แม้ลบผลงานต้นทาง

## ขอบเขตสิทธิ์

ข้อมูลผูกกับผู้ใช้ที่เข้าสู่ระบบฝั่งเซิร์ฟเวอร์ ทุกหน้ารายการ รายละเอียด การแก้ไข ไฟล์ ดาวน์โหลด และการเปลี่ยนแปลงตรวจเจ้าของบัญชี ผู้ดูแลระบบไม่มีสิทธิ์เปิดผลงานส่วนตัวของบัญชีอื่นผ่านโมดูลนี้ การลบเป็น soft delete และการแก้ไขตรวจ RowVersion ป้องกันการเขียนทับหน้าที่เปิดค้างไว้

กิจกรรมและรางวัลโรงเรียนยังใช้สิทธิ์และขั้นตอนอนุมัติเดิม ผลงานส่วนตัวไม่เผยแพร่สู่เว็บไซต์สาธารณะอัตโนมัติ แฟ้มยื่นเรียนต่อยังใช้ได้เฉพาะ Student

## ฐานข้อมูลและตรวจสอบ

Migration `20260927043848_AddPersonalWorks` เพิ่ม `portfolio.PersonalWorks` และ `portfolio.PersonalWorkMedia` พร้อม foreign keys, owner index, rowversion และ constraint ให้ไฟล์แนบมีแหล่งข้อมูลหนึ่งประเภทเท่านั้น (ไฟล์ในระบบหรือลิงก์)

```powershell
dotnet build SchoolPortfolioPR.sln
dotnet ef database update --project SchoolPortfolioPR
dotnet run --project SchoolPortfolioPR --no-build --urls http://localhost:5093
# อีก terminal ใช้บัญชีทดสอบที่สร้างไว้ใน artifacts/private/test-accounts.json
dotnet run --project SchoolPortfolioPR.UiChecks --no-build -- --my-works
```

ชุดทดสอบสร้างข้อมูลชั่วคราวผ่านหน้าจอทุกบัญชี ตรวจไฟล์ไบนารี พรีวิว คำบรรยาย ลิงก์ การตรวจเจ้าของ การแก้ไขพร้อมกัน คัดลอก PDF และลบเฉพาะข้อมูลที่ชุดทดสอบสร้างเมื่อจบ ภาพหน้าจออยู่ใน `artifacts/ui/myworks` ซึ่งไม่ส่งเข้า Git
