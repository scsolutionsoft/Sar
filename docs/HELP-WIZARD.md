# Slug อัตโนมัติและตัวช่วยใช้งาน

## URL ข่าว

เมื่อสร้างกิจกรรมใหม่ ระบบสร้าง Slug จากรหัสกิจกรรมที่ปรับให้เป็นตัวอักษรอังกฤษ/ตัวเลข/ขีดกลาง พร้อมรหัสสุ่มเฉพาะรายการ ถ้ารหัสกิจกรรมไม่มีตัวอักษรที่ใช้ใน URL ได้ จะใช้ `news` เป็นคำนำหน้า ช่อง URL ข่าวเป็นแบบอ่านอย่างเดียว ไม่ต้องกรอก

ระบบตรวจชื่อซ้ำและมี unique index ในฐานข้อมูลรองรับ การแก้ชื่อข่าวหรือรหัสกิจกรรมไม่เปลี่ยน Slug เดิม รวมถึงข่าวที่สร้างก่อนการปรับระบบนี้ ค่า Slug ที่ส่งจากเบราว์เซอร์ถูกละเว้น

ลิงก์ข่าวใช้ `/news/{ปี พ.ศ. ของวันที่กิจกรรม}/{slug}` และเปิดได้เมื่อสถานะเป็น Published และ IsPublic เป็นจริง จากนั้นพาไปหน้ารายละเอียดกิจกรรม การสร้าง Slug ไม่ได้เปลี่ยนสถานะเผยแพร่ และการเปลี่ยนวันที่ไปคนละปียังเปลี่ยนส่วนปีของ URL ตามกติกาเดิม

## ตัวช่วยใช้งานตามบทบาท

เปิดเมนู **ตัวช่วยใช้งาน (Wizard)** หรือปุ่มแนะนำในหน้าภาพรวม/แฟ้มยื่นเรียนต่อ แล้วเลือกหัวข้อ ระบบแสดงเฉพาะหัวข้อที่ตรงกับสิทธิ์ของบัญชี

- ทุกบัญชี: เริ่มต้นใช้งาน กิจกรรม รางวัล คลังภาพ วารสาร คลัง PDF ส่วนตัว และรายงาน
- นักเรียน: เพิ่มหัวข้อแฟ้มยื่นเรียนต่อ แนะนำรางวัล/เกียรติบัตรเฉพาะตน ไม่มีหัวข้อแฟ้มผลงานโรงเรียน
- บทบาทอื่น: มีหัวข้อแฟ้มผลงานโรงเรียนตามสิทธิ์อ่านเดิม
- ผู้มีสิทธิ์สร้าง: ขั้นตอนบันทึกกิจกรรม/รางวัล เลือกผู้ร่วมกิจกรรม แนบหลักฐาน และส่งตรวจ
- ครู/ผู้ดูแลฝ่าย/ผู้อนุมัติ/ประชาสัมพันธ์/แอดมิน: ขั้นตอนในคิวงานตามบทบาทจริง
- ผู้เผยแพร่: จัดกระดานประชาสัมพันธ์และสร้างวารสาร
- SuperAdmin และ Administrator: ข้อมูลพื้นฐาน ตั้งค่าชื่อ/โลโก้ และ Audit
- SuperAdmin: จัดการบัญชี บทบาท และผูกทะเบียนนักเรียน

แต่ละหัวข้อมีปุ่มก่อนหน้า/ถัดไป รายการขั้นตอน และปุ่มเปิดหน้าทำงานในแท็บใหม่ ปุ่ม “อ่านครบแล้ว” บันทึกความคืบหน้าการอ่านเท่านั้น ไม่ได้ดำเนินงานแทนผู้ใช้ สามารถเริ่มหัวข้อใหม่หรืออ่านต่อจากจุดเดิมได้

ความคืบหน้าเก็บใน localStorage แยกตามบัญชีและชุดบทบาทในเบราว์เซอร์นั้น ไม่ซิงก์ข้ามอุปกรณ์ และเมื่อปิดการเก็บข้อมูลในเบราว์เซอร์ คู่มือยังอ่านและเลื่อนขั้นตอนได้ตามปกติ เมื่อไม่ใช้ JavaScript ยังเปิดหัวข้อและใช้ก่อนหน้า/ถัดไปได้

เส้นทาง `/Help` และ `/Help/Wizard` ต้องเข้าสู่ระบบ หัวข้อที่ไม่มีสิทธิ์ตอบ 404 แม้พิมพ์ URL เอง และทุกหน้าทำงานปลายทางยังใช้การตรวจสิทธิ์เดิม ไม่มีการขยายสิทธิ์จากคู่มือ

ทดสอบด้วย `dotnet run --project SchoolPortfolioPR.UiChecks -- --help-wizard` ขณะเว็บเปิดที่ localhost:5093 ใช้ทั้ง 9 บัญชีทดสอบและลบกิจกรรมชั่วคราวเมื่อจบ การปรับครั้งนี้ไม่เพิ่มตารางหรือ migration
