# ตัวเลือกครูและนักเรียนร่วมกิจกรรม

หน้าเพิ่ม/แก้ไขกิจกรรม และหน้าเพิ่ม/แก้ไขรางวัลใช้ชุดเลือกรายชื่อเดียวกัน

- ครู: เลือกกลุ่มสาระ แล้วพิมพ์ชื่อหรือรหัสเพื่อกรองทันที
- นักเรียน: เลือกระดับชั้นและห้อง แล้วพิมพ์ชื่อหรือรหัสเพื่อกรองทันที ห้องจะปรับตามระดับชั้นที่เลือก
- เลือกได้หลายคน รายชื่อที่เลือกแสดงด้านล่างพร้อมรหัสเพื่อแยกคนชื่อซ้ำ เปลี่ยนตัวกรองแล้วรายชื่อเดิมยังคงอยู่
- “เลือกที่พบทั้งหมด” เพิ่มทุกรายชื่อที่ตรงกับตัวกรองปัจจุบัน “ล้างตัวกรอง” ไม่ลบรายชื่อที่เลือก ส่วนปุ่ม × นำออกทีละคน และ “ล้างที่เลือกทั้งหมด” นำออกทั้งหมด
- กด Enter ในช่องค้นหาไม่ส่งฟอร์มโดยไม่ตั้งใจ รายชื่อที่เลือกคงอยู่เมื่อกรอกข้อมูลไม่ครบ และกลับมาแสดงเมื่อเปิดแก้ไข
- รองรับมือถือ คีย์บอร์ด และช่องเลือกมาตรฐานเมื่อ JavaScript ไม่ทำงาน

กลุ่มสาระอ่านจากทะเบียนครู ระดับชั้น/ห้องอ่านจากช่องชั้นเรียนเดิม เช่น `ม.6/1`, `ป.3/2`, `ม.4 ห้อง 3` รองรับตัวเลขไทยและข้อมูลที่ไม่ได้ระบุชั้น/ห้อง โดยไม่แก้ไขข้อมูลทะเบียนเดิม หากต้องการปรับกลุ่มของบุคคล ให้ผู้ดูแลแก้ในข้อมูลพื้นฐานของครูหรือนักเรียน

ชื่อฟิลด์ที่บันทึกยังเป็น `TeacherIds` และ `StudentIds` เซิร์ฟเวอร์ตรวจบุคคลและสิทธิ์บันทึกตามเดิม รายชื่อและข้อความทั้งหมดแสดงแบบข้อความ ไม่ตีความชื่อเป็น HTML

## ผลตรวจ

- Build ไม่มี warnings/errors และ unit tests ผ่าน 49 กรณี รวมการแยกระดับชั้น/ห้องจากรูปแบบเดิม
- `UiChecks --participants` ผ่าน: กรองกลุ่มสาระ ค้นชื่อครูชื่อซ้ำตามรหัส กรองชั้น/ห้องที่สัมพันธ์กัน ค้นไม่พบ เลือกข้ามตัวกรอง เลือกทั้งหมด ล้างและนำออกทีละคน
- ทดสอบกรอกไม่ครบแล้วเลือกไม่หาย บันทึกและเปิดแก้ไขกิจกรรม/รางวัล ตรวจความสัมพันธ์ใน SQL รวมถึงเปลี่ยนตัวบุคคลในรางวัล ผ่าน
- ชื่อที่มีเครื่องหมาย HTML แสดงเป็นข้อความ มือถือ 390px ไม่ล้น และปิด JavaScript แล้วยังเลือกด้วยช่องมาตรฐานได้ ไม่มี JavaScript errors
- ลบเฉพาะทะเบียนและรายการชั่วคราวที่สร้างเพื่อทดสอบแล้ว ภาพตรวจอยู่ใน `artifacts/ui/participants/`

```powershell
dotnet run --project SchoolPortfolioPR.UiChecks -- --participants
```
