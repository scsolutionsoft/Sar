# ข้อมูลตัวอย่างสำหรับทดสอบ

เพิ่มภาพสต็อกประกอบครบ 10 กิจกรรม พร้อมภาพปกและแกลเลอรีแล้ว ภาพทั้ง 10 ไฟล์และเอกสารตัวอย่าง 7 ไฟล์เก็บเป็นไบนารีใน SQL Server (`varbinary(max)`) ดู [แหล่งภาพ เครดิต และคำสั่งนำเข้าภาพ](SAMPLE-IMAGE-SOURCES.md)

คำสั่งนี้เพิ่มกิจกรรมสมมติ 10 รายการ `DEMO-ACT-001` ถึง `DEMO-ACT-010` ลงฐานข้อมูลที่กำหนดใน User Secrets/environment พร้อมครูตัวอย่าง 5 คน นักเรียนตัวอย่าง 10 คน รางวัล 4 รายการ เกียรติบัตร PDF 4 ไฟล์ และเอกสารประกอบกิจกรรม PDF/DOCX/XLSX อย่างละ 1 ไฟล์

```powershell
dotnet run --project SchoolPortfolioPR.Seed
# ตรวจข้อมูลและตรวจหน้าจอ (เปิดเว็บที่ localhost:5093 ก่อน)
dotnet run --project SchoolPortfolioPR.Seed -- --verify --verify-ui
```

กิจกรรมมีสถานะ Draft 2, Submitted 2, Reviewed 1, Approved 1, Published 2, Rejected 1 และ Archived 1. มีวันที่กระจายในช่วง 48 วันก่อนวันเพิ่มข้อมูลเพื่อใช้ทดสอบตัวกรองและกราฟ กิจกรรมและรางวัลทุกชิ้นปิดการเผยแพร่สาธารณะ (`IsPublic = false`) แม้บางรายการเป็นสถานะ Published

เข้าระบบด้วยบัญชีผู้ดูแล แล้วเปิด `/Activities?q=DEMO-ACT-` หรือค้นหา `[ตัวอย่าง]`. ครูและนักเรียนใช้ชื่อสมมติชัดเจนเพื่อไม่ปะปนกับบุคคลจริง ข้อมูลหลักที่เพิ่มใหม่ใช้ชื่อมีคำว่า `(ตัวอย่าง)` และใช้แท็ก `ข้อมูลตัวอย่าง`.

รันคำสั่งเพิ่มข้อมูลซ้ำจะข้ามรหัสกิจกรรมที่มีอยู่แล้ว ไม่เขียนทับการแก้ไขของผู้ใช้และไม่กู้คืนรายการที่ลบแล้ว การเพิ่มใช้ transaction และบันทึก Audit ในนามบัญชีผู้ดูแลจาก configuration. ถ้าต้องการทดลองเผยแพร่ข่าวหรือเลือกลงวารสาร ให้ผู้ดูแลเปิดเผยแพร่สาธารณะในกิจกรรมที่ต้องการเอง
