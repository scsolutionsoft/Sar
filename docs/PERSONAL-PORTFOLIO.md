## คลัง PDF `/Documents`

ระบุชื่อ หมวดหมู่ วันที่ และรายละเอียด แล้วอัปโหลด PDF หรือเขียนรายงานให้ระบบสร้าง PDF ใหม่ รองรับไม่เกิน 10 MB และ 100 หน้า ไม่รับไฟล์ติดรหัสผ่าน ค้นหา กรองหมวดหมู่ เปิดป๊อปอัป และดาวน์โหลดได้

หน้า `/Reports` มีปุ่มบันทึกรายงานที่แสดงตามตัวกรองลงคลัง PDF ส่วนตัว เอกสารที่ใช้เป็นหลักฐานในแฟ้มต้องนำออกจากแฟ้มก่อนลบ หากจะเปลี่ยนไฟล์หลักฐานให้เพิ่มเอกสารใหม่เพื่อเก็บต้นฉบับเดิม

## แฟ้มยื่นเรียนต่อ `/Admissions`

1. เพิ่มประวัติ สถานศึกษา แผนการเรียน GPAX ประวัติการศึกษา และช่องทางติดต่อ
2. ระบุคณะ/มหาวิทยาลัย รอบรับสมัคร ลิงก์ประกาศ เหตุผลที่เลือกเรียน และเป้าหมาย
3. ใส่ทักษะหนึ่งรายการต่อบรรทัด เช่น `การนำเสนอ | 80` จะแสดงเป็นกราฟประเมินตนเอง หรือใช้ข้อความ เช่น `ภาษาอังกฤษ | B1`
4. เลือกธีม Academic, Botanical, Creative ภาพปก สารบัญ และหน้าปิดท้าย
5. เพิ่มโครงงาน กิจกรรม รางวัล จิตอาสา หรือเกียรติบัตร พร้อมบทบาท กระบวนการ ผลลัพธ์ สิ่งที่เรียนรู้ ภาพ และลิงก์ผลงาน ใช้ปุ่มขึ้น/ลงหรือลากเพื่อจัดลำดับ
6. เลือกผลการเรียน หนังสือรับรอง หรือหลักฐาน PDF จากคลัง จัดลำดับได้ เอกสารซ้ำระหว่างผลงานกับรายการแนบท้ายจะรวมเพียงครั้งเดียว
7. ตั้งจำนวนหน้าและขนาดไฟล์สูงสุดตามประกาศ แล้วสร้าง PDF ระบบรวมทุกหน้าของหลักฐาน ตรวจจำนวนหน้าและขนาดจริงก่อนบันทึก ถ้าเกินจะแจ้งให้แก้ไข
8. เปิด Flipbook ใช้ปุ่มลูกศร สารบัญ ซูม เต็มจอ หรือปัดบนมือถือ แล้วดาวน์โหลด PDF เพื่อนำไปยื่น

รายการเตรียมข้อมูลช่วยระบุหัวข้อที่ยังขาด ไม่ใช่การรับรองว่าผ่านเกณฑ์ทุกมหาวิทยาลัย จำนวนหน้าที่ระบบตรวจรวมปก สารบัญ และหลักฐานทั้งหมด ผู้ใช้ต้องปรับตามประกาศของคณะที่ยื่น ซึ่งอาจนับหน้าไม่เหมือนกัน ตัวอย่างแหล่งตรวจเกณฑ์: [มหาวิทยาลัยเชียงใหม่ Portfolio 2570](https://admission.reg.cmu.ac.th/tcas/findportfolio.php?id=88)

ตัวอย่างใช้ข้อมูลสมมติ เกรดและหลักฐานไม่มีผลรับรองจริง แก้เป็นข้อมูลของตนก่อนยื่น เครดิตภาพใน [SAMPLE-IMAGE-SOURCES.md](SAMPLE-IMAGE-SOURCES.md)

## การจัดเก็บและสิทธิ์

ตาราง `portfolio.PersonalDocuments`, `AdmissionPortfolios`, `PortfolioEntry`, `PortfolioDocument` แยกเจ้าของด้วย OwnerId ฝั่งเซิร์ฟเวอร์ ทุกเส้นทางอ่าน แก้ไข ลบ จัดลำดับ ดูตัวอย่าง สร้าง PDF และ `/files/{id}` ตรวจเจ้าของ ไฟล์เก็บใน `FileObjects.FileData` ชนิด `varbinary(max)` ไม่มีไฟล์อัปโหลดใน wwwroot

การแก้ไขแฟ้มหรือผลงานยกเลิก PDF ก่อนหน้า ต้องสร้างใหม่เพื่อใช้ข้อมูลล่าสุด ใช้ RowVersion ตรวจการแก้ไขทับและการแก้ระหว่างสร้าง PDF พร้อม Audit และ soft delete URL ของแฟ้มยังเป็นส่วนตัว ให้ดาวน์โหลด PDF เพื่อส่งสถาบัน บันทึก Audit ของรายการส่วนตัวเก็บเฉพาะรหัสรายการ เจ้าของ และสถานะการลบ ไม่คัดลอกเนื้อหาประวัติ ผลงาน หรือข้อมูลติดต่อไปให้ผู้ดูแลอ่าน

Chromium จัดหน้าด้วยฟอนต์ Sarabun ในโปรเจค จากนั้น [PDFsharp 6.2.4](https://docs.pdfsharp.net/PDFsharp/Overview/Introduction.html) รวมหน้าหลักฐานโดยไม่แปลงเป็นภาพ ไฟล์ต้นฉบับยังแยกจากฉบับรวม

```powershell
dotnet ef database update --project SchoolPortfolioPR
dotnet run --project SchoolPortfolioPR -- --seed-test-users
dotnet test SchoolPortfolioPR.Tests
# เปิดเว็บ localhost:5093 ก่อน
dotnet run --project SchoolPortfolioPR.UiChecks -- --personal
```

ตัวสร้างบัญชีสุ่มรหัสผ่านแยกแต่ละบัญชี เก็บแบบ Identity hash ในฐานข้อมูล เพิ่มเฉพาะบัญชีที่ยังไม่มี ไม่รีเซ็ตรหัสผ่านเดิม ไฟล์ credentials สำหรับ UI tests อยู่ใน artifacts/private ไม่พิมพ์รหัสผ่านใน log ชุดทดสอบสร้าง fixture แยกและลบเฉพาะข้อมูลทดสอบของรอบนั้น หลักฐานหน้าจออยู่ใน `artifacts/ui/admission-*.png`
