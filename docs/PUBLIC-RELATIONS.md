# กระดานประชาสัมพันธ์หน้าแรกและวารสารตัวอย่าง

## การใช้งาน

เข้าสู่ระบบด้วยบทบาท SuperAdmin, Administrator หรือ PRAdmin แล้วเลือกเมนู **กระดานประชาสัมพันธ์** (`/Announcements`) กดเพิ่มข่าว ระบุหัวข้อ ข้อความสั้น รายละเอียด และหมวดหมู่

เลือกขนาดกรอบ **เล็ก / กลาง / ใหญ่** และโทนสี กำหนดลำดับแสดง (เลขน้อยขึ้นก่อน; หากเท่ากัน ข่าวที่สร้างใหม่ขึ้นก่อน) บนจอใหญ่กรอบใหญ่ใช้พื้นที่กว้างครึ่งหน้าและสูงสองแถว กลางกว้างครึ่งหน้า เล็กกว้างหนึ่งในสี่หน้า บนมือถือทุกขนาดเรียงหนึ่งคอลัมน์

เลือกภาพจากคลังกิจกรรมที่แสดงในฟอร์ม หรืออัปโหลด JPG/PNG/WebP ไม่เกิน 10 MB มีตัวอย่างกรอบให้ดูทันที ข่าวไม่จำเป็นต้องมีภาพ สามารถใช้พื้นหลังสีแทนได้ ภาพที่เลือกจากกิจกรรมจะคัดลอกเป็นไฟล์ของข่าวเอง เพื่อไม่ผูกสิทธิ์การเผยแพร่กับกิจกรรมต้นทาง คลังภาพแสดง 200 ภาพล่าสุด หากภาพที่ต้องการไม่อยู่ในรายการให้อัปโหลดไฟล์ใหม่

ระบุ **เริ่มแสดงวันที่** และ **แสดงถึงวันที่** เป็น ค.ศ. แล้วเลือก **เปิดแสดงบนหน้าแรกตามกำหนดเวลา** ระบบนับวันตามเวลาไทย UTC+7 และแสดงจนจบวันสุดท้าย ข่าวล่วงหน้า ข่าวหมดอายุ ข่าวปิดแสดง และข่าวที่ลบจะไม่ปรากฏในหน้าแรก รวมถึงเปิด URL ข่าวหรือภาพโดยผู้เข้าชมทั่วไปไม่ได้ ผู้ดูแลยังเปิดดูตัวอย่างได้ ระบบตรวจช่วงเวลาเมื่อเปิดหรือโหลดหน้าใหม่ ไม่ต้องตั้ง scheduled task

ข่าวแต่ละกรอบมีปุ่มอ่านประกาศ และปุ่มขยายภาพซึ่งใช้ป๊อปอัปชุดเดียวกับภาพ/PDF ในส่วนอื่น ๆ การแก้ไขใช้ RowVersion ป้องกันการบันทึกทับกัน มี Audit และ soft delete เช่นเดียวกับข้อมูลหลัก

## ตัวอย่างที่เพิ่มลงฐานข้อมูล Sar

- `DEMO-PR-001` ถึง `DEMO-PR-006`: ข่าวตัวอย่าง 6 กรอบที่เปิดแสดง คละขนาดพร้อมภาพ
- `DEMO-PR-007`: ข่าวล่วงหน้า เริ่ม 7 วันหลังวันสร้างตัวอย่าง
- `DEMO-PR-008`: ข่าวหมดอายุ สิ้นสุดก่อนวันสร้างตัวอย่าง 1 วัน
- `[ตัวอย่าง] เรื่องเล่าจากรั้วโรงเรียน`: วารสารเดือนกันยายน 2569 ที่ `/publications/2569/9` มี PDF 12 หน้า พร้อมภาพปก สาร สารบัญ เนื้อหา ประมวลภาพ และสถิติ
- `PR-DEMO-ACT-001` ถึง `PR-DEMO-ACT-003`: เรื่องราวสมมติสาธารณะสำหรับวารสาร แยกจากกิจกรรมตัวอย่างเดิม 10 รายการที่ยังเป็นส่วนตัว

ข่าวตัวอย่างที่กำลังแสดงเริ่มวันที่ 19 กันยายน 2569 และสิ้นสุดวันที่ 26 ตุลาคม 2569 ผู้ดูแลเปลี่ยนวันหรือปิดแสดงได้จากหน้าแก้ไข ภาพเป็นภาพสต็อกและข่าวเป็นเรื่องสมมติ โดยระบุคำว่าตัวอย่างในหัวข้อ ดูเครดิตที่ [SAMPLE-IMAGE-SOURCES.md](SAMPLE-IMAGE-SOURCES.md)

ภาพกระดานข่าวและ PDF วารสารเก็บจริงใน `portfolio.FileObjects.FileData` ชนิด `varbinary(max)` พร้อมขนาดและ SHA-256 ไม่มีการ hotlink ภาพภายนอก

## คำสั่งสำหรับผู้พัฒนา

```powershell
dotnet ef database update --project SchoolPortfolioPR
dotnet run --project SchoolPortfolioPR.Seed -- --pr-demo
dotnet test SchoolPortfolioPR.Tests
# เปิดเว็บที่ localhost:5093 ก่อนทดสอบหน้าจอ
dotnet run --project SchoolPortfolioPR.UiChecks -- --pr
```

Migration `AddScheduledAnnouncements` เพิ่มเฉพาะตาราง `portfolio.Announcements` และดัชนี/ข้อจำกัดที่เกี่ยวข้อง ไม่เปลี่ยนโครงสร้างไฟล์ไบนารีเดิม ตัวนำเข้าข้ามข่าวที่มี ReferenceCode เดิมและกิจกรรมที่มี ActivityCode เดิม ไม่รีเซ็ตช่วงเวลาเมื่อรันซ้ำ และสร้างวารสารในเดือนว่างล่าสุดหากเดือนปัจจุบันมีฉบับอื่นอยู่แล้ว

UI checks สร้างข่าวทดสอบแยกต่างหาก ตรวจการสร้าง/แก้ไข เลือกและอัปโหลดภาพ การตั้งเวลา การปิดแสดง การลบและสิทธิ์ไฟล์ แล้วลบเฉพาะ fixture และสำเนาไฟล์ที่สร้างโดยการทดสอบนั้น หลักฐานหน้าจออยู่ใน `artifacts/ui/pr-*.png`
