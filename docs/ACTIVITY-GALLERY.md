# คลังภาพกิจกรรม

เปิดเมนู **คลังภาพกิจกรรม** (`/Gallery`) เพื่อค้นหาจากชื่อกิจกรรม รหัส หรือคำบรรยายภาพ แล้วเลือกอัลบั้ม ระบบแสดงเฉพาะกิจกรรมที่บัญชีมีสิทธิ์อ่านตามกติกาเดิม

ผู้ที่มีสิทธิ์แก้ไขกิจกรรมจะเห็นปุ่มเพิ่มรายการในส่วน **คลังภาพกิจกรรม** ของหน้ารายละเอียด มีสองโหมด:

- **อัปโหลดภาพ**: เลือก PNG, JPG หรือ WebP พร้อมคำบรรยายได้หลายภาพ สูงสุด 20 ภาพต่อครั้ง ภาพละไม่เกิน 10 MB และรวมไม่เกิน 50 MB ไฟล์เก็บเป็นไบนารีในฐานข้อมูล คลิกภาพเพื่อเปิดป๊อปอัปพรีวิวร่วมกับระบบเดิม
- **ลิงก์จากคลาวด์**: วาง URL แบบ HTTPS หรือ HTTP ของภาพ/อัลบั้ม เช่น Google Drive, OneDrive หรือบริการอื่น พร้อมคำบรรยาย ระบบเก็บเฉพาะ URL การ์ดแสดงชื่อเว็บไซต์และเปิดลิงก์นั้นในแท็บใหม่ ไม่ดึงไฟล์จากคลาวด์มาเก็บหรือพรีวิว ผู้ชมใช้สิทธิ์แชร์ที่กำหนดไว้ในบริการต้นทาง

คำบรรยายไม่บังคับและยาวได้ไม่เกิน 500 ตัวอักษร การอัปโหลดหลายภาพใช้คำบรรยายเดียวกันในครั้งแรก แล้วแก้แต่ละภาพได้ด้วยปุ่ม **แก้ไขคำบรรยาย** ถ้าเว้นว่าง รูปในระบบแสดงชื่อไฟล์ ลิงก์คลาวด์ใช้ข้อความเริ่มต้น

รูปเดิมของกิจกรรมยังอยู่ครบและเพิ่มคำบรรยายได้ ภาพปกและการจัดลำดับภาพในระบบใช้ส่วนจัดการเดิม ส่วนลิงก์คลาวด์เรียงตามลำดับที่เพิ่มและแก้ URL/คำบรรยาย หรือนำลิงก์ออกได้ การนำลิงก์ออกไม่ลบไฟล์ในคลาวด์

นักเรียนและผู้ชมอ่านได้ตามสิทธิ์กิจกรรม แต่เพิ่ม/แก้ไข/ลบรายการไม่ได้ ครูแก้ไขกิจกรรมที่ตนมีสิทธิ์ในสถานะฉบับร่าง/ส่งกลับ ผู้ดูแลจัดการได้ตามสิทธิ์เดิม รายการที่เปลี่ยนโดยผู้อื่นระหว่างเปิดแบบฟอร์มจะปฏิเสธการบันทึกทับและให้เปิดหน้าใหม่

เพิ่มคอลัมน์ `portfolio.ActivityImage.Caption` และตาราง `portfolio.ActivityImageLinks` ด้วย migration `20260927034408_AddActivityGalleryLinksAndCaptions` โดยไม่ย้ายหรือลบไบนารีเดิม การเปลี่ยนแปลงบันทึก Audit ตามปกติ วารสาร PDF ที่สร้างจากระบบเดิมยังใช้ภาพที่อัปโหลดในระบบ ส่วนลิงก์คลาวด์เปิดจากคลังภาพ

ทดสอบ: เปิดเว็บที่ localhost:5093 แล้วเรียก `dotnet run --project SchoolPortfolioPR.UiChecks -- --gallery` ชุดทดสอบใช้ภาพและกิจกรรมชั่วคราว และลบข้อมูลรอบทดสอบหลังจบ
